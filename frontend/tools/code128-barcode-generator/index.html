Each Code 128 symbol is eleven modules wide: three bars and three spaces, one to four modules each. Set B carries one printable ASCII character per symbol and set C carries two digits, so this page switches to C only where the switch saves a symbol — four digits at either end of the text, or six or more in the middle. The check symbol is the weighted sum of the start and data symbols modulo 103 and is drawn before the stop pattern. Quiet zones of ten modules sit at both ends; choose the module width your label and scanner need and test-scan a print before a production run. FNC codes and GS1-128 application identifiers are not offered, and everything runs in your browser with no storage, uploads or network access.
