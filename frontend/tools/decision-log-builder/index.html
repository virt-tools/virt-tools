Decision Log Builder

Record decisions, rationale, relationships, reviews, and follow-up actions locally.

This tool makes no network requests. Your log stays only in memory and is lost on reload unless you explicitly choose Save in this browser, which uses this browser's local storage. Avoid sensitive material on shared devices. JSON is the round-trip format; Markdown and CSV are readable but lossy. Limits: 1,000 decisions, 2 MiB per import, and 200 entries per list.

Portable data

JSON version 1 preserves every supported field and is validated without silent truncation on import. Markdown flattens relationships and structured options/actions. CSV includes one row per decision, joins lists, omits some fields, and prefixes formula-like cells with an apostrophe for spreadsheet safety; both text formats are lossy.
