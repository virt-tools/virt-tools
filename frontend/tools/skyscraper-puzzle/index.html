Skyscraper Puzzle

Fill the grid with towers of heights 1 to N so every row and column contains each height once. A clue at the edge counts how many towers you can see from that side; taller towers hide the shorter ones behind them. Runs locally in your browser.

Keys: arrow keys move between cells, 1–6 enter a height, Backspace clears a cell, C checks, N starts a new puzzle.

Each clue is the number of towers visible along that row or column from that edge. Every row and column must hold each height exactly once, and every puzzle here has exactly one solution. Puzzles are built and checked inside this page or from a fixed set that was checked the same way — no account, storage or network requests.
