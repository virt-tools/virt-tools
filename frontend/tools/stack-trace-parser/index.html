    Local editor links

    Links are off by default and are only displayed locally. Templates must use an allowed protocol: vscode:, vscode-insiders:, idea:, subl:, txmt:, or file:. Available placeholders are {file}, {line}, and {column}.

    Limits: 300,000 characters, 10,000 input lines, and 5,000 displayed results. Unmatched non-empty lines are preserved in JSON.
