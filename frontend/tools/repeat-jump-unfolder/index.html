Played order

How the model reads a score. Sections are listed in printed order and each written repeat is taken where the score places it. On a D.C. or D.S. jump the repeat pass starts at the first section or the Segno and plays forward; written repeats are skipped there unless the box is ticked. al Fine stops after the Fine section, and al Coda leaves at To Coda, then plays from the Coda section to the end. With a Coda, the first pass plays every section before the Coda block and then jumps, so the Coda is heard only on the repeat pass. Bar numbers count performed bars from the first played bar, not printed bar numbers or time. Pickup bars, fermatas, tempo changes, nested voltas and repeats that end inside a jump target are not modelled: this is a reading order and a bar count, not playback.
