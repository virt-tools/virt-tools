CharacterCodeBecomesWhy

A search filter follows RFC 4515: NUL, * ( ) and \ become a backslash and two hex digits, because a bare * is a wildcard and a bare bracket ends the assertion. A distinguished-name value follows RFC 4514: a backslash goes before " + , ; < > and \, a leading # and any leading or trailing space are hex-escaped, while = and / need no escape. Escaping non-ASCII writes each UTF-8 byte, which some older directory clients expect. Reading reverses either form and refuses a broken escape or bytes that are not valid UTF-8. The page works on one attribute value; it does not parse or assemble a whole filter or DN. Everything runs in your browser; nothing is sent or stored.
