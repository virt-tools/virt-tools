Critical Path Planner

Calculate a deterministic finish-to-start CPM network locally. Results are planning arithmetic, not delivery promises.

Tasks

Dependencies use IDs with optional signed day lag: A, A+2, or A-0.5. Model: finish-to-start, continuous days, finite nonnegative durations. Every task is constrained to start at or after project offset 0. Limits: 500 tasks, 5,000 dependency edges, 1,000 enumerated critical paths, and 1 MiB of task text.

Import CSV or JSON

Date mapping is display-only and uses UTC. CPM offsets remain continuous-day values. Weekday projection requires a Monday–Friday start, skips weekends for each whole offset day, and retains the fractional day to millisecond precision.
