    Available plates pairs on the rack

    One pair is one plate on each side. Set a size to 0 when it is not on the rack; the load above updates as you change it.

    How the plates are chosen

    • Both sides match. Every result is one plate count per side, loaded symmetrically, so the total is the bar plus twice the plates on one side.
    • Biggest plates first, then an exact check. The calculator searches every combination of the pairs you listed, smallest increment first, and reports the combination that hits the target exactly. If none does, it shows the closest lighter and heavier loads it can build instead of rounding silently.
    • The rack limits the result. A full rack is four pairs of each size; lower a size to zero when the plates are already on another bar. The nearest options change as soon as a size runs out.
    • Weight only. Collars, clips and bar flex are not included, and plate markings vary between sets — check the stamp on the plate before you lift. This is loading arithmetic, not lifting or safety advice.
    • Everything runs in your browser: no storage, uploads or network requests.
