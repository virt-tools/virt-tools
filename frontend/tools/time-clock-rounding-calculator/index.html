Rounding is applied to a grid that starts at midnight, so every policy lands on the same minute values whatever the date. A clock-out earlier than the clock-in is read as the next day, which is how an overnight shift is entered. The page rounds hours only: it does not compute pay, overtime or legal compliance, and a rounding practice is acceptable only where it averages out over time.
