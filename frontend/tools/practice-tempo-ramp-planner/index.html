Enter a start and target tempo to build the ladder.

Seconds per pass = beats per pass × 60 ÷ tempo. Each step lasts passes per step × seconds per pass, and between steps the rest time is added. The ladder starts at your start tempo and rises by the step size until it reaches the target; if the range does not divide evenly the last step is shorter, and with a target above the start tempo the target is always the final step. This plans the session only: it does not play the metronome and stores nothing. Tempos are used exactly as entered, so 63.5 BPM stays 63.5 BPM.
