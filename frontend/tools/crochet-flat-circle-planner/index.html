Round-by-round plan

Each later round adds the same number of stitches as the starting ring. The size estimate treats each round as one measured round-height of radius, so diameter is twice the accumulated radius. Yarn, hook, stitch type and tension can change the result; make a small swatch and adjust if the fabric cups or ruffles.
