Plus Code Converter

Convert between latitude / longitude and an Open Location Code — the short “Plus Code” address used by Google Maps (e.g. 9C3XGV4C+XV for central London). Encode a position at 8, 10 or 11 characters, or decode a code back to its centre and bounding box. Pure arithmetic, in your browser.

full code, or a short code with a reference
A short code omits its leading characters; the reference point decides which full code it means.

A Plus Code uses a 20-character alphabet that omits 0, 1, I, L, O and U. Every pair of characters narrows a 20° × 20° cell by a factor of 20, so eight characters locate a roughly 275 m square, ten characters about 14 m, and the eleventh character about 3 m. Short codes drop the leading pairs that name the region and are recovered from a nearby reference point — how near depends on how many characters were dropped. Latitude 90 is nudged a fraction south so the code still decodes, and longitude 180 is read as −180. Everything runs locally with no storage, uploads or network access.
