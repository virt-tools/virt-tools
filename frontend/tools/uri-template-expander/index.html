URI Template Expander

Paste an RFC 6570 template such as /repos/{owner}/{repo}/issues{?state,labels*,per_page} and a JSON object of variable values. The page expands every expression and shows what each operator did.

Template and variables

Literals plus expressions in braces. Operators: + # . / ; ? &, value modifiers :3 and *. Ctrl+Enter expands from either field.

Strings, numbers and booleans expand to strings; arrays and objects become lists and name/value pairs. null or a missing key means undefined.

Expression by expression

Every expression is listed here once the template expands.

    How an expression expands

    • Operator first. The character right after { picks the prefix and separator: {.var} is a dot label, {/var} a path segment, {;var} a path parameter, {?var} a query, and {+var} / {#var} keep reserved characters instead of encoding them.
    • Undefined values vanish. A missing key or null is skipped, and an expression whose variables are all undefined expands to nothing at all, prefix included.
    • Modifiers. :N keeps the first N characters of a string value and is refused on lists and objects; * explodes a list or object into repeated name or segment parts.
    • Encoding. Values are percent-encoded as UTF-8, except for the unreserved set; reserved expansion also lets unreserved-plus-reserved characters and existing %XX triplets through unchanged.
