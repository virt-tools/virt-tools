Download a runnable sender for exactly this packet. Each file carries the MAC, the SecureOn tail if you set one, and the broadcast defaults, accepts an optional host and port, and uses only what the language ships with — no libraries to install beyond the shell one's socat.

A magic packet is six ff bytes followed by the target MAC repeated sixteen times — 102 bytes, or 108 with a six-byte SecureOn password on the end. It is sent as a UDP datagram to the limited broadcast address 255.255.255.255 on port 9 (some equipment listens on port 7). Browsers cannot send raw UDP, so run one of these files, or copy the hex into a wake tool, a switch or router wake action. The card only answers on the same Layer 2 segment, and Wake-on-LAN must be enabled in the firmware with standby power present. Separators in the MAC are optional, and the dotted Cisco form is accepted. Everything runs in your browser with no storage, uploads or network access.
