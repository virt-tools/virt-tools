Cron Syntax Converter

Translate practical schedules between Unix cron, Quartz, AWS EventBridge, and systemd. The converter never pretends the dialects are identical: unsupported or changed semantics are called out beside every result.

Source schedule

Unix order: minute hour day-of-month month day-of-week.

Translations

Dialect reference

DialectField orderImportant differences
Unixminute hour DOM month DOWNo seconds/year. When DOM and DOW are both restricted, most implementations use OR.
Quartzsecond minute hour DOM month DOW [year]Requires ? in either DOM or DOW. Supports L, W, and #, which are not universally portable.
AWS EventBridgeminute hour DOM month DOW yearUTC by default; one of DOM/DOW must be ?. Some special wildcards have AWS-specific restrictions.
systemdDOW YYYY-MM-DD HH:MM:SSCalendar-event syntax, not cron fields. Date and weekday restrictions combine rather than using Unix DOM/DOW OR behavior.

Names are accepted case-insensitively. This tool handles lists, ranges, and steps in ordinary cron fields. Advanced Quartz/AWS tokens are validated as dialect syntax but deliberately not guessed into another dialect.
