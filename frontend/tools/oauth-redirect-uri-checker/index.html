The check models the comparison an authorization server is told to make. With a fully registered URI it applies simple string comparison, so case, percent-encoding and a trailing slash all count (RFC 6749 section 3.1.2.3 via RFC 3986 section 6.2.1). When only the scheme, authority and path are registered, the query may vary. A loopback IP redirect on http may use any port (RFC 8252 section 7.3). Providers can be stricter or more forgiving than this, and registration consoles sometimes normalise a value on save, so treat a rejection here as the first thing to check, not as the provider's final answer. Nothing is sent, stored or uploaded.
