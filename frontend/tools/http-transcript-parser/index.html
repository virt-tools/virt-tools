HTTP Transcript Parser

Inspect bounded HTTP/1.x request and response transcripts without sending requests or rendering bodies.

Text inspection only: URLs are never fetched, HTML is never rendered, and bodies are never executed. Paste one or more messages separated by a line beginning ---. Unframed bodies require that separator. Optional timing syntax: --- timing=123.4ms before a response.

Transcript input

Limits: 2 MiB after UTF-8 encoding, 500 messages, 1,000 header/trailer lines per message, 64 KiB per framing line, and 1 MiB decoded body per message. CRLF and LF are accepted; bare CR is not. This text input cannot reproduce arbitrary binary captures. Exported body hex preserves the UTF-8 bytes parsed from this field; the UI preview shows at most 4 KiB.
