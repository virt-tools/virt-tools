systemd Path Unit Builder

Create a path watcher and its companion oneshot service. Nothing is executed or uploaded.

Generator only: review both files before installing them. Path activation uses inotify and does not observe changes made by other machines on remote NFS filesystems. Trigger-limit directives require systemd 250 or newer.

Path trigger

Base name only; matching .path and .service suffixes are added.
One per line, up to 32 unique paths. Globs are interpreted only by PathExistsGlob.
For example 500ms, 2s or 1min; 0 disables this limit.
0 or a positive integer up to 1,000,000.
Four-digit octal mode used only with MakeDirectory.

Companion oneshot service

One argument per line. The executable must be absolute; empty arguments are unsupported.
Optional absolute path.
Optional existing account name.
