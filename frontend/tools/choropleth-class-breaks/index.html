    How the breaks are placed

    • Equal interval. The full range is split into classes of the same width: w = (max − min) / k, and the breaks are min + i·w. Every class spans the same number of units, which suits a value with a natural unit such as hectares or millimetres of rain, but a single outlier can push nearly every area into the first class.
    • Quantile. The values are sorted and the breaks are read off the order statistics at i/k of the way through, with linear interpolation between neighbouring values (the same definition as the type 7 quantile in R and NumPy's default). Each class then holds roughly the same number of areas, which spreads the shades evenly but hides how far apart the values really are.
    • Which class a value joins. A class includes its lower bound and excludes its upper bound, so a value sitting exactly on a break joins the class above it; the top class also includes the maximum. When a value repeats across a break the class between them is empty, and the tool says so rather than pretending the shade exists.
    • Rounding. Breaks are rounded to six significant figures of the data range before values are counted — four decimals for a range in the hundreds, none for a range in the billions — so the ranges in the table are exactly the values that were counted.
    • What it does not do. No natural-breaks (Jenks) optimisation, no data classification by area, and no projection or geometry: this works on the attribute values alone. Everything runs in your browser with no storage, uploads or network access.
