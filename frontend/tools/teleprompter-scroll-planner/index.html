The script is measured, not recorded: every run of whitespace between words collapses to one space, each line is wrapped greedily at the character width, and a word longer than that width sits alone on its own line. Each line takes the line height, and a blank line takes one line too, so the script height is the line count times the line height. Read time is 60 times the word count divided by the reading rate; scroll speed is the script height divided by that time, and one screen of text passes in the screen height divided by the speed. With a target slot, the required pace is 60 times the word count divided by the slot, and the required speed is the height divided by the slot. A monospaced, constant-speed scroll is assumed: character widths, paragraph spacing beyond the blank lines, the last lines sitting below the reading line and any prompter speed ramp are not modelled, so treat the speed as a starting point and trim it on the prompter. Everything runs in your browser with no storage, uploads or network access.
