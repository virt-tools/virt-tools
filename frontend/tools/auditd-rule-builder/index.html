The kernel checks syscall rules for every program on the machine, so keep the rule count low and combine syscalls in one rule. On a 64-bit x86 machine the 32-bit compatibility calls are a separate table, which is why the both option writes two lines with b32 and b64. A directory watch follows the whole subtree but stops at a mount point below it. This page only composes text: it reads nothing from your machine and cannot load, list or remove rules.
