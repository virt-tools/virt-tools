Interval Ear Trainer

Hear two notes and name the distance between them. Pick a level and a direction, then answer each round; the trainer keeps your accuracy and streak. Runs locally in your browser.

Choose a level and press Start practice. Each round plays two notes; name the interval you heard.

Keys: 1–9 answer the first nine choices, Space replays the notes (or moves on once answered), N is Next interval, R replays.

Intervals are measured in semitones in 12-tone equal temperament, with A4 = 440 Hz. Each round picks a random root inside a comfortable range, so the same interval does not always sound from the same pitch. Notes are synthesised locally with the Web Audio API — no audio files, microphone or network access. Changing the level starts a new round but keeps your score; changing the direction replays the current interval the other way.
