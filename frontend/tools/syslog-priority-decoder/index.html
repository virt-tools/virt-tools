Severities (0–7)

Facilities (0–23)

A syslog priority is one number from 0 to 191: facility × 8 + severity. RFC 5424 and the older BSD format both put it first in angle brackets, so <34> is facility 4 (auth) and severity 2 (crit). journald stores the severity as PRIORITY and journalctl --priority takes the same keywords shown here. Facility 15 is the solaris-cron slot that RFC 5424 calls a second clock daemon, and every facility can carry any severity. RFC 5424 forbids leading zeros, so <034> is refused rather than silently read as 34. Decoding is a lookup in this page: nothing is executed, stored or sent anywhere.
