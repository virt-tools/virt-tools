The count uses the Web Mercator XYZ scheme: at zoom z the world is 2z tiles wide and high, a longitude of lon falls at column (lon + 180) / 360 × 2z and a latitude of lat at row (1 − asinh(tan lat) / π) / 2 × 2z. Every tile the box touches is counted, including the partial ones along each edge, so a box that ends exactly on a tile boundary does not claim the next tile. The estimated size is the tile count times the average tile size you enter, summed per level and rounded to the nearest byte; real caches vary with imagery detail, compression and whether tiles are served as 256 px or 512 px. Latitudes stop at ±85.05112878° because that is where Web Mercator runs out, and only this projection is handled. Tile services set their own usage policies and rate limits, so check them before a bulk download. Everything runs in your browser with no storage, uploads or network access.
