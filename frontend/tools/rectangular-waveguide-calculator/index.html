The TE10 cutoff is c / 2a for the broad wall of an air-filled guide, with c = 299,792,458 m/s. The next modes cut off at c / a (TE20) and c / 2b (TE01), and the lower of the two sets the top of the single-mode range. Above cutoff, guide wavelength, phase velocity and wave impedance all scale by 1 / √(1 − (fc/f)²) and group velocity by √(1 − (fc/f)²), so vp·vg = c². The usable band is shown as 1.25 to 1.9 times the TE10 cutoff, the usual single-mode margin. A dielectric filling lowers every cutoff by √εr, which this page does not model. Everything is calculated in this page.
