    Installing the file
    

      

    1. Save it as /etc/systemd/network/10-enp1s0.network, owned by root with mode 0644.
      2. 

    2. Make sure only one manager configures the link: NetworkManager and systemd-networkd must not both handle the same interface. Set the device unmanaged in NetworkManager, or disable it.
      3. 

    3. Enable and reload: sudo systemctl enable --now systemd-networkd, then sudo networkctl reload.
      4. 

    4. Check the result: networkctl status enp1s0 and ip address show enp1s0.
      5. 

    

    systemd-networkd reads these files in lexical order and the first .network file that matches an interface is used, so the numeric prefix decides precedence; a second matching file with a lower number wins instead. This page generates text only: it cannot read your host, change permissions, or reload systemd-networkd, and the file uses IPv4 addresses for DNS servers.
