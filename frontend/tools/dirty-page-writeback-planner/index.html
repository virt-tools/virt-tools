    Linux starts background writeback of dirty pages at one percentage of available memory and makes the writing process start writeback itself at a higher one. The ratios set those two limits; vm.dirty_background_bytes and vm.dirty_bytes set the same limits directly. Thresholds here are RAM × ratio rounded to whole MiB, so they are an upper bound — the kernel measures against free plus reclaimable pages, not total RAM. The model assumes a constant write rate and device throughput; it does not model writeback congestion, cgroup v2 dirty limits or per-device limits.
