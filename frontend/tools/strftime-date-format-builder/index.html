strftime Date Format Builder

Write a date format with the C strftime codes and see the result for a Unix time and a UTC offset. Every code in your format is expanded and explained below it.

Whole seconds since 1970-01-01 UTC, for any year from 1 to 9999.

For example +02:00 or -05:00, from -12:00 to +14:00.

Mix text and codes; unknown codes are left as written.

Format codes this page supports
CodeMeaning

The codes are the C and POSIX strftime set, plus the GNU -, _ and 0 padding flags for the fixed-width number fields. Weekday and month names are always English, so the result does not depend on a locale. %Z shows the offset (UTC or UTC+05:30), not an IANA zone abbreviation, and daylight-saving rules are not looked up: enter the offset in force at that instant. %c, %x, %X and %D use the English C-locale forms. The page does not round or clamp: the Unix time is used exactly as entered, and %s returns it unchanged. Everything is computed in this browser: nothing is stored and nothing is sent.
