Legal (limited) luma coding puts reference black at code 16 and reference white at code 235 in 8 bits, so 100 IRE spans 219 codes and 1 IRE is 2.19 codes; 10-bit and 12-bit values are simply the 8-bit scale multiplied by 4 and by 16, giving 64 and 940 for black and white in 10 bits. Full (data) range uses the whole container, so code 0 is 0 IRE and code 255 is 100 IRE. Code below 16 or above 235 is not automatically an error — footroom and superwhite are legal excursions — but a level outside 0 to 100 IRE will be clipped by a legal-range encoder, and the status row says by how much. The tool works on luma only, treats IRE as a linear percentage of the encoded range, and does not model the display transfer function, chroma, gamut, HDR transfers or noise; use the HDR transfer function converter for PQ and HLG luminance. Everything runs locally in your browser.
