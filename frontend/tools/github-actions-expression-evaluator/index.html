GitHub Actions Expression Evaluator

Evaluate a ${{ }}  expression from a workflow if:, env: or runs-on: against your own contexts, and see the value and whether the step would run.

Paste it with or without the ${{ }} wrapper. Strings use single quotes; the language has no arithmetic operators.

Each key is a context; one you leave out evaluates to null. The JSON is read in this browser and never sent anywhere.

This follows the expression language as GitHub documents and implements it: literals, the operator table, loose equality with its coercion table, the built-in functions and object filters. Comparison ignores case for strings, && and || return one of their operands rather than a boolean, a missing property is null, and * collects a property or the items of a collection into an array. An if: condition runs when its value is truthy and, unless the expression calls success(), failure(), cancelled() or always(), when the job is still succeeding, which is the implicit success() check. hashFiles() needs the workflow workspace and is refused, and secrets is never available inside an expression. The page uses your browsers own JSON parser for the contexts and evaluates everything locally: nothing is stored and nothing is sent.
