Pitch-Class Set Analyzer

Name the set class behind any group of notes: normal order, prime form, Forte number and interval vector.

Note names with accidentals (C, F♯, E♭, B♭♭) or numbers from 0 to 11, separated by spaces or commas. C is 0 and B is 11; duplicates are counted once.

Normal order is the rotation of the set that spans the fewest semitones, compared from the top down when two rotations tie. Prime form follows Rahn: take the set and its inversion, put each into normal order starting on 0, and keep the lower of the two — so C major and C minor both reduce to 0, 3, 7. The Forte number is the standard catalogue label for that prime form, with Z marking the pairs of set classes that share an interval vector without being transpositions or inversions of each other. The interval vector counts, for each interval class from 1 to 6, how many note pairs in the set are that far apart. The complement is the set of the other pitch classes. Register, voicing and doubling are ignored, and nothing here says whether a set sounds tonal, atonal or good. It runs entirely in your browser with no storage, uploads or network access.
