Coordinate List Cleaner

Parse decimal or DMS coordinates, review likely swaps, normalize precision, and remove duplicates without network access.

Local syntax processing only: no geocoding, datum transformation, map lookup, or network request occurs. Coordinates are treated as WGS 84-style latitude/longitude values but their real-world accuracy and datum cannot be verified. Swap suggestions are never applied silently.
