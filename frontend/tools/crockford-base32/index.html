Crockford Base32 Encoder / Decoder

Convert whole numbers to and from Douglas Crockford's Base32 — a 32-symbol alphabet that leaves out I, L, O and U so a code survives being read aloud, typed or copied by hand. An optional check symbol (the value modulo 37) catches mistyped and transposed symbols. Everything is computed locally.

Decimal digits, or prefix 0x for hexadecimal. Whitespace and underscores are ignored. Enter converts; Shift+Enter starts a new line.

Base32 writes a number in base 32, five bits per symbol, using the 32 characters 0-9 and A-Z without I, L, O and U. Encoding uses upper-case letters only and the shortest form: leading zeros are dropped, so a code has no fixed width and is not a byte encoding. Decoding accepts upper or lower case, reads I, i, L and l as 1 and O and o as 0, and ignores hyphens and whitespace. With the check symbol enabled, the last symbol encodes the number modulo 37, using the five extra symbols * ~ $ = U, and a mismatch is reported instead of a value. Nothing is uploaded, stored or sent anywhere.
