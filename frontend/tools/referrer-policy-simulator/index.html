PolicyReferer header

A referrer policy decides how much of the page URL goes into the Referer header. The full form is the page URL without its fragment, username or password; the origin form is scheme, host and port followed by a slash. A downgrade is HTTPS to HTTP only — HTTP to HTTPS keeps the full URL. With no header the spec falls back to no-referrer-when-downgrade, while browsers use strict-origin-when-cross-origin as their default. URLs must be plain ASCII here; nothing is uploaded, stored or fetched.
