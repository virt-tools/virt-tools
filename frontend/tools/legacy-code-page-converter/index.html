Legacy Code Page Converter

Map text to and from single-byte legacy code pages, including EBCDIC, with the code point for every byte.

Each page maps every one of the 256 byte values to one Unicode code point, so conversion is a direct table lookup.

Up to 4,096 characters. Characters the page cannot represent are written as 0x3F (“?”) and counted below.

Choose Convert to bytes to encode the sample text with Windows-1252.

Tables follow the published Unicode mappings for CP437, CP850, Windows-1252, ISO-8859-1, CP037 and CP500. Bytes 0x00–0x1F and 0x7F keep their C0 and delete code points; a DOS or 3270 screen may draw those positions as symbols instead. Undefined Windows-1252 bytes (0x81, 0x8D, 0x8F, 0x90, 0x9D) are reported rather than guessed. This is a character conversion, not encryption, and nothing leaves your browser.
