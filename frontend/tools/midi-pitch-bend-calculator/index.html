MIDI Pitch Bend Calculator

A pitch bend message is a fourteen-bit number, and how far it moves the pitch depends on the bend range the receiving instrument is set to. Enter a value to read the offset in semitones and cents, or enter the offset you want to get the value, its data bytes and the whole message.

The bend range is the sensitivity the receiver is set to, usually through RPN 0: 2 semitones on many hardware synths, 12 or 24 in software instruments. The value is the fourteen-bit position, from 0 at full down through 8192 at centre to 16383 at full up.

A pitch bend message is sent as a status byte 1110nnnn for the channel, then the seven-bit least-significant byte and the seven-bit most-significant byte of the fourteen-bit value; the page shows the same three bytes. Centre is 8192 (2000H) and no pitch change, and the top of the travel reaches 8191/8192 of the range rather than the full range, because the value is asymmetric about its centre. The offset only becomes semitones through the bend range, which the receiver holds and which this page cannot read: if the instrument is set to a different range, the same value sounds a different interval. Some devices ignore the least-significant byte and use only coarse steps, so a value that this page resolves finely may move the pitch in jumps there. Pitch bend never changes the note number, and notes retuned by more than a couple of semitones depend on the instrument's own limits. Everything runs locally in your browser; nothing is uploaded and no MIDI device is contacted.
