Docker Compose Validator

Check common Compose structure and risky defaults, then map services and resources. Parsing stays in your browser.

Scope: This is a practical YAML subset checker, not the Docker Compose specification. Anchors, aliases, tags, block scalars, merge keys, and advanced YAML syntax are rejected. Confirm production files with docker compose config.

Checks included
