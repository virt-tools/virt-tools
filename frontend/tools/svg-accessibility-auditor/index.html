SVG Accessibility Auditor

Inspect SVG structure locally without rendering or executing it. Results are guidance, not a WCAG conformance claim.

Nothing leaves this browser. The SVG is parsed as inert XML and is never inserted into the page.

Limits and interpretation

  • 50,000 elements, depth 128, 250,000 attributes, and 2,000,000 text characters.
  • DOCTYPE and ENTITY declarations are rejected before parsing.
  • Accessible names depend on the embedding context and assistive technology. Review findings manually.
  • External URLs, active content, and CSS URL/import syntax are reported separately as security findings.
