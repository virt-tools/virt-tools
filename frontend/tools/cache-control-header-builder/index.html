    How caches read this header

    The header is a comma-separated list of directives, and the list is only as strong as its weakest combination: a response marked no-store is not cached no matter what max-age says.

    • Freshness is a countdown, not an expiry date. max-age=3600 means the copy stays fresh for an hour after it was generated; while fresh, a cache may reuse it without asking the origin. When it goes stale, most caches ask again.
    • max-age and s-maxage are different audiences. max-age applies to the browser and to any shared cache. s-maxage overrides it for shared caches only, which is how a CDN can keep a page for ten minutes while the browser keeps it for one — and s-maxage also implies proxy-revalidate for shared caches.
    • public and private decide who is allowed to store. private keeps a copy in the browser only, which is what per-user responses want; public matters when a response would otherwise be excluded, such as one carrying an Authorization header.
    • no-cache still allows storing. It only forces validation before every reuse, so a conditional request can come back 304 Not Modified. no-store is the one that forbids storing at all. Neither is the same as max-age=0, which lets a cache keep and reuse a stale copy under the usual stale rules.
    • immutable is for names that never change. With a hashed filename the URL's bytes cannot change, so immutable lets even a reload skip revalidation while the response is fresh. It does nothing without a positive max-age.
    • stale-while-revalidate and stale-if-error buy time. The first lets a cache serve the stale copy while it fetches a new one in the background; the second lets it serve the stale copy if the origin errors. Both need a stored response and a max-age to have anything to serve.
    • Not modelled. No Age, Vary, ETag or Last-Modified handling, no Expires header, no cache key configuration, no CDN-specific rules or purge behaviour, and no heuristic-freshness estimate beyond naming it. This builds the header string only; everything runs in your browser.
