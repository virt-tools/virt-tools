Model assumptions: One source backup exists every hour from the first backup through the planning end, inclusive. Each tier retains the newest source point in each eligible calendar bucket: hour, day, Monday-based week, month, or year. Windows are measured from the planning end; overlapping selections are deduplicated. UTC uses UTC calendar fields; local mode uses this browser’s calendar and daylight-saving rules. A source point is modeled as full every N×24 source intervals from the first backup; all others use the entered incremental percentage. This is a capacity estimate—not a restore-chain, compression, deduplication, failure, immutability, or provider billing simulation.
