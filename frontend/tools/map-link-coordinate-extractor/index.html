Map Link Coordinate Extractor

Paste a map link or a coordinate pair and get the latitude and longitude in decimal, in degrees-minutes-seconds and as a geo: URI, plus the zoom and the precision the link carries.

The link is read as text in your browser; nothing is fetched, stored or sent anywhere. Recognised shapes are a place pin, a dropped marker, a map view fragment, a map centre parameter, a map view centre, a latitude and longitude parameter pair, a geo: URI and a plain decimal pair with optional N, S, E or W letters. Latitude always comes first, so a value above 90 in the first position is reported as a likely swap. Decimal places in the source decide the precision line: each step of the last digit is that many metres of latitude, and the east-west step shrinks with the cosine of the latitude.
