Aerobic decoupling compares how much work you produced per heartbeat in the first and second half of a steady session. The efficiency factor is speed in metres per minute divided by average heart rate; decoupling is the percentage by which that factor falls from the first half to the second, so a positive number means heart rate rose (or pace fell) and a negative number means heart rate fell relative to the output. A commonly used guideline for an aerobic base session is under 5% once warm-up is excluded; 5–10% is moderate drift and above 10% is high drift. The number is only meaningful when both halves are genuinely comparable: same route or trainer, similar terrain, cadence and fuelling, no stops, and a steady effort throughout. Heat, dehydration, caffeine, illness, poor sleep and a harder first half all push heart rate up without any loss of fitness, so read one session as a signal and a repeated pattern as the trend. This is a training-analysis figure, not a medical measurement. Everything runs in your browser; nothing is sent or stored.
