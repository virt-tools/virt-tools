Score Page Layout Planner

Work out how many systems fit on one page of sheet music, and how many pages the score needs.

The two gaps are counted in staff spaces, the distance between adjacent staff lines: LilyPond's default staff height is 20 pt, and 20 pt is 7.03 mm, so one staff space is a little over 1.75 mm.

A system is one line of music: every staff that is played together, joined by a bracket. Casting off a score means deciding how many of those lines fit down a page, and the answer is set by the space the staves take, not by the music. Each staff is four staff spaces tall, so the staff height is the staff space multiplied by four; one point is 2540/7227 mm, the printers' point LilyPond uses. A system's block is the staves stacked with the gap between staves counted in staff spaces, and the gap between systems is added between one block and the next, so the vertical pitch of a system is the block plus that gap. Systems per page is the number that fit in the printable height (paper height less both margins), and pages is the number of systems divided by that count, rounded up. The model assumes even spacing and counts no title block or page number: LilyPond treats a title as a system, so subtract its height from the printable area before entering the number of systems, and ragged bottoms leave the last page short. It also says nothing about page turns, which depend on rests worth turning over. No network request is made, and nothing is stored.
