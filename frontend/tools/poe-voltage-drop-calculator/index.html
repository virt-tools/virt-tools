    How the drop is worked out

    • Loop resistance. Current leaves the switch on one pair and returns on another. Each pair is two conductors in parallel, so for a 2-pair standard the loop is one conductor's resistance per metre times the run length: Rloop = R′·L. With all four pairs in use (802.3bt Type 3 and Type 4) the two paths sit in parallel, so Rloop = R′·L/2.
    • Copper resistance. A conductor's resistance follows R′ = ρ/A with annealed copper ρ = 1.724×10−8 Ω·m at 20 °C, and the cross-section from the AWG diameter d = 0.127 mm × 92(36−n)/39. That gives about 0.084 Ω/m for 24 AWG and 0.067 Ω/m for 23 AWG.
    • Constant power, not constant current. A powered device is a DC-DC converter, so it draws whatever current keeps its input power fixed: as the voltage sags the current rises. Solving Vpd = Vs − I·Rloop together with P = Vpd·I gives I = (Vs − √(Vs2 − 4·Rloop·P)) / (2·Rloop), and the device voltage is P/I. When the discriminant is negative the cable simply cannot carry that load at that voltage.
    • Class floors. The standard guarantees a minimum voltage at the device: 37.0 V for 802.3af (12.95 W, 350 mA), 42.5 V for 802.3at (25.5 W, 600 mA) and for 802.3bt Type 3 (51 W over four pairs, 600 mA), and 41.1 V for 802.3bt Type 4 (71.3 W, 960 mA). The longest run is where the device sits exactly on that floor.
    • What it assumes. A steady load at 20 °C copper, no connector, patch-lead or bundling effects, and a cable of the stated gauge end to end. The 100 m channel limit of TIA-568 is independent of voltage: a run that clears the floor at 180 m still breaks the channel limit, so the tool flags both.
