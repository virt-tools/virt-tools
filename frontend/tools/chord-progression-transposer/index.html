Chord Progression Transposer

Transpose chord-symbol text while preserving extensions, alterations, parentheses, slash bass notes, spacing, and unknown tokens.

Parsing is intentionally conservative. Token mode assumes standalone chord tokens and can transpose an isolated word “A” as the chord A. Line-safe mode preserves an entire line if any non-divider token is unknown, making it safer for prose or lyrics. Roman analysis only labels unaltered scale-degree roots and does not infer harmonic function, borrowed chords, or enharmonic intent.
