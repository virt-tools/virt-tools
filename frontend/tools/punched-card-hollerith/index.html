Punched Card (Hollerith) Code

Type text and see it punched onto 80-column cards in the IBM 029 character set — every character is a 12-row column of holes, with the zone punches in rows 12, 11 and 0 and the digit punch in rows 1 to 9.

80 columns per card, up to 8 cards. Lowercase is raised to capitals; a new line starts a new card.

Read one column

IBM 029 card code 64 characters

Each column shows the 12 punch positions top to bottom: rows 12, 11, 0, then 1 to 9. A filled mark is a hole; the code under each character lists the punched rows, zone first.

The 12, 11 and 0 rows are the zone punches and 1 to 9 are the digit punches. A letter is one zone punch plus one digit punch (A is 12-1, J is 11-1, S is 0-2); a digit is a single hole in rows 1 to 9, with 0 punched in row 0 alone; a symbol adds the row 8 punch between the zone and the digit, so a period is 12-8-3. Space is a column with no holes, and 0-8-2 is the keypunch blank used to clear a column. Card codes varied between keypunches: the 029 set shown here gives ¢ and ¬ to 12-8-2 and 11-8-7, where other machines print brackets or a caret, but the zone and digit rows are the same. This is a historical reference: it draws the holes, it does not read a scanned card or drive a keypunch. Everything runs in this browser — nothing is stored, uploaded or sent.
