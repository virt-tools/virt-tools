Metric modulation keeps one pulse sounding the same while its note value changes. Tempi here are quarter-note BPM, and note values are measured in quarter notes — whole 4, dotted half 3, half 2, dotted quarter 1.5, quarter 1, dotted eighth 0.75, eighth 0.5, dotted sixteenth 0.375, sixteenth 0.25, thirty-second 0.125, half-note triplet 4/3, quarter-note triplet 2/3 and eighth-note triplet 1/3 — so the new tempo is the old tempo × new value ÷ old value. If the old dotted quarter (750 ms at 120 BPM) becomes the new quarter, the new tempo is 120 × 1 ÷ 1.5 = 80 BPM, and every new quarter lasts the same 750 ms. Dots multiply a value by 1.5 and triplets multiply it by 2/3. This is notation timing, not a groove or performance model; nothing is uploaded or stored, and the page never contacts the network.
