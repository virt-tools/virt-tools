The 12-color sequence

Loose-tube cables color both the buffer tubes and the fibers inside them in this order, counting from 1.

Standard fiber and tube colors
No.Color

Colors follow the widely used TIA-598 sequence. Colors repeat after 12: a tube with 24 fibers uses a second pass (positions 13 to 24), usually marked with a stripe, and cables with more than 12 tubes repeat the tube colors in groups marked by a tracer or binder. Marking conventions differ between manufacturers, so check the cable datasheet before relying on a repeat. This tool counts from the start of the cable and does not model ribbon, unitized or slot-core constructions. Nothing is stored and the page makes no network requests.
