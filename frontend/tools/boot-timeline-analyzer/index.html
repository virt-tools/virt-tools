Boot Timeline Analyzer

Compare pasted systemd boot timing reports without executing commands or reading the local host.

Pasted reports

This optional subset accepts only unit @start +duration text lines; duration may be omitted. It does not parse, render, or trust systemd's SVG plot markup.

Interpretation limits: a high blame duration is activation time, not proof that the unit delayed the boot target. The critical chain is target- and timing-dependent, can omit parallel work, and is not a causal optimization prescription. Indentation is reproduced as a reported parent/child hierarchy; this page does not verify the underlying relationship type. Output wording, glyphs, precision, and available fields vary across systemd versions and locales; this parser expects English unit suffixes and decimal points.
