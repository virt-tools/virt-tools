Formatter scope and safety

This is a structure-aware formatter, not a SQL parser or validator. The dialect choice recognizes common dialect-specific keywords and quoting, but does not certify syntax. Formatting preserves token text inside single quotes, double quotes, backticks, square-bracket identifiers, comments, and PostgreSQL dollar-quoted strings. Always review generated SQL before executing it.
