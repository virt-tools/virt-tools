A switch's bridge ID is its 2-byte priority followed by its 48-bit MAC address, and the lowest bridge ID wins the root election, so priority is compared before the MAC and a switch at 4096 beats one left at the default 32768. Every other switch forwards on the port that offers the lowest root path cost; equal offers are broken by the lowest upstream bridge ID, then the lowest upstream port ID, then the lowest local port ID, with ports numbered in the order the links appear. On each link the side advertising the better path cost, bridge ID and port ID becomes the designated port; a port that is neither root nor designated is an alternate and stays blocked, which is what removes the loop. Costs use the IEEE 802.1t rule of thumb 20,000,000 divided by the link speed in Mb/s, which reproduces the standard values from 10 Mb/s (2,000,000) through 100 Gb/s (200). The model assumes point-to-point links, at most one link per pair of switches, equal port priorities and a single common spanning tree (STP, RSTP or the CIST of MSTP), so it does not cover per-VLAN trees, shared hubs, port cost overrides or BPDU filtering. Everything runs locally in your browser.
