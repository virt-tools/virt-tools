IPv6 Transition Address Decoder

Paste an IPv6 address from a log, a routing table or a tunnel interface and see which transition mechanism built it, which IPv4 address it carries and which UDP port it hides.

One address: no prefix length, brackets or zone ID. A dotted IPv4 tail is accepted.

Only for a network-specific prefix, 32 to 96 bits. Leave empty for the well-known 64:ff9b::/96.

MechanismPrefix or interface IDIPv4 field

Teredo2001:0::/32Server 32 to 63; client 96 to 127, obfuscated
ISATAP0000:5EFE:w.x.y.z or 0200:5EFE:w.x.y.zLast 32 bits of the interface ID

A transition address is an ordinary IPv6 address whose bits were laid out by a transition mechanism, so it can be read back without any query: 6to4 puts the site's public IPv4 address in bits 16 to 47 of the 2002::/16 prefix, giving the site the 2002:V4ADDR::/48 prefix and sending its traffic to the 6to4 relay anycast address 192.88.99.1, a mechanism RFC 7526 deprecated because that anycast address was withdrawn. Teredo puts the Teredo server's IPv4 address in bits 32 to 63, then 16 bits of flags, then the client's mapped UDP port and IPv4 address with every bit inverted, which is undone by exclusive-OR with 0xFFFF and 0xFFFFFFFF; the only defined flag bit is 0x8000, which a client sets when it believes it sits behind a cone NAT. ISATAP is not a prefix but an interface identifier: 0000:5EFE followed by the node's IPv4 address in network byte order, or 0200:5EFE when that IPv4 address is globally unique, so the same identifier appears under a link-local, a unique-local or a global prefix. NAT64 embeds the IPv4 address in the IPv4-converted address, either after the well-known prefix 64:ff9b::/96 or, for a network-specific prefix of 32, 40, 48, 56, 64 or 96 bits, split around the reserved octet at bits 64 to 71, which must be zero; the bits after the embedded address are reserved and should also be zero. A network-specific NAT64 prefix cannot be recognised from the address alone, which is why the second field exists. Every mechanism here is local arithmetic on the address you paste: the page makes no DNS query, opens no connection to the address and sends nothing anywhere.
