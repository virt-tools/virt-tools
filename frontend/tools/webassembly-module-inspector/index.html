WebAssembly Module Inspector

Inspect a local Wasm module’s binary structure without compiling, executing, or uploading it.

Module input

Limits: 8 MiB decoded input, 256 sections, 100,000 entries per vector, 200,000 decoded entries total, 5,000 findings, and 25 previewed records per section. This is a structural version-1 decoder, not a validation engine: GC/recursive types, most name and element payloads, and instruction streams are not decoded. Feature observations come from decoded structure, so instruction-only features may be missed. No execution, compilation, linking, uploads, or network requests.
