    Authenticator data is at least 37 bytes: a 32-byte RP ID hash, one flags byte and a 4-byte signature counter. The flags byte carries User Present (0x01), User Verified (0x04), Backup Eligibility (0x08), Backup State (0x10), Attested credential data (0x40) and Extension data (0x80), with bits 0x02 and 0x20 reserved. When 0x40 is set, 16 bytes of AAGUID, a 2-byte credential ID length of at most 1,023 bytes, the credential ID and a COSE key follow; when 0x80 is set, a CBOR map of extensions closes the structure. The COSE key is read far enough to report its kty and alg parameters. This page does not verify a signature, check an attestation statement or trust the AAGUID: it only decodes the bytes you paste. Everything runs in your browser with no storage, uploads or network access.
