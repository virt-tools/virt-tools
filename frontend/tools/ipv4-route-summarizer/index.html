IPv4 Route Summarizer

Paste a list of IPv4 prefixes and get the smallest set of CIDR routes that covers exactly the same addresses, the single supernet that holds them all, and every entry that added nothing. Everything is worked out in your browser; nothing is uploaded, stored or sent anywhere.

Prefixes to summarize

One prefix per line; spaces and commas work too. CIDR only, up to 64 prefixes, host bits must be clear.

    What this does not do

    • It summarizes IPv4 prefixes only. IPv6 aggregation works on different boundaries and is not attempted here.
    • It keeps the address set exactly: it merges only prefixes that touch and are aligned, so nothing is announced that was not given. That is why the result can still be several prefixes.
    • The covering supernet is arithmetic, not a routing recommendation: announcing it also announces the gaps between your blocks, and it may cross a network you do not control.
    • It ignores everything a real router would weigh: AS paths, policy, longest-prefix behaviour, metrics and how the prefixes arrived. It reads no routing table and keeps no record; reloading the page clears your entries.
