With a charge-pump phase detector the open-loop gain is G(s) = (Icp / 2π) · KVCO · Z(s) / (N s), where Z(s) = (1 + s R2 C1) / (s (C1 + C2) (1 + s R2 C1 C2 / (C1 + C2))). The filter places a zero at fz = 1 / (2π R2 C1) and a pole at fp = (C1 + C2) / (2π R2 C1 C2). The page solves |G(j 2π fc)| = 1 for the loop bandwidth and reports the phase margin φ = atan(fc / fz) − atan(fc / fp). The damping figure is the second-order estimate ζ = √K / (2 · 2π fz), which ignores the filter pole. This is the continuous-time linear model: phase-detector sampling, divider delay, VCO input capacitance, charge-pump mismatch, and reference and supply spurs are not modelled. Everything is calculated in this page; nothing is sent or stored.
