A workflow runs when the event matches and every ref and path filter is satisfied. branches and paths are globs where * stops at a slash and ** crosses it; ? and + repeat the character before them, and a leading ! subtracts from the patterns above it. The last matching pattern decides, so a later positive pattern re-includes a path. Path filters are not evaluated for tag pushes, and defining only branch filters means a tag push never runs. Activity types (types:), schedule, reusable-workflow and dispatch inputs are not modelled, and nothing leaves this page.
