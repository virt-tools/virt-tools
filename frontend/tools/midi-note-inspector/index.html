MIDI Note Inspector

Parse Standard MIDI Files locally and inspect tracks, channels, notes, metadata, timing, tempo maps, and pairing diagnostics.

Inspection only: files are never uploaded or played. This parser supports Standard MIDI File types 0, 1, and 2—not raw MIDI streams, RIFF RMID containers, or proprietary sequencer formats.


Maximum 5 MiB, 256 tracks, 200,000 parsed events.
