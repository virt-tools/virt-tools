A closed GOP starts with a keyframe and runs for the encoder's keyframe interval, so keyframes fall on whole multiples of the GOP length from the first frame of the file. A stream copy can only start on a keyframe: to keep the requested out point exactly, the copy has to run to the next keyframe and the two ends are decoded or re-encoded. The out point is treated as the last frame kept, so a 25 fps cut from 00:00:10:10 to 00:00:11:24 keeps forty frames. Keyframes inserted at scene cuts, open GOPs and encoders that vary the interval will move the real boundaries, so use this as the plan and check the file's keyframe list before a final lossless export. Use a semicolon before the frame count for drop-frame timecode at 29.97 or 59.94 fps; at other rates only the colon form is accepted.
