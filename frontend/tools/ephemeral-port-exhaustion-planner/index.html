Per source IP unless marked aggregate

Each completed outbound connection holds a source port for TIME_WAIT (2 × MSL, 60 s by default), so a steady rate of r connections per second pins about r × TIME_WAIT ports at once — Little's law. Linux defaults to net.ipv4.ip_local_port_range = 32768 60999; Windows uses 49152–65535. Listener ports and ports below 1024 are never ephemeral. Load balancers, NAT gateways and proxies share one pool per source address, which is why per-IP headroom matters. Estimates only; all arithmetic stays in your browser.
