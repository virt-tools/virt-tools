Motorola S-Record Inspector

Paste an S-record file and check it record by record: checksums, address widths, the record count, gaps, overlaps and the entry point.

One record per line, each starting with S and a type digit. Blank lines are ignored; spaces and comments are not part of the format.

Each line is a record: S, a type digit, CC the byte count, then the address, the data and SS the checksum. The byte count is the number of bytes after it — address plus data plus the checksum byte — so a 16-byte S1 record carries 13. The checksum is the one's complement of the low byte of the sum of the byte count, the address bytes and the data, so a correct record adds up to FF. S0 is a header, usually holding a module name; S1, S2 and S3 carry data at a 2, 3 or 4-byte address; S5 and S6 state how many data records precede them; S7, S8 and S9 end the file and may name the start address. S4 is not defined. Everything is checked in your browser; nothing is uploaded or stored.
