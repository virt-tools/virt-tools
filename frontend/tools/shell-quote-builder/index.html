Shell Quote Builder

Paste any text and get a shell word that expands back to exactly that text: the single-quoted form POSIX sh understands, plus the bare, double-quoted and bash ANSI-C forms when they are safe. Each one is read back by the page's own quote-removal parser, so you can see it reproduces the text. Switch to decoding to paste a quoted word and see the value quote removal produces. Everything runs in your browser; nothing is uploaded, stored or sent anywhere.

        What this does not do

        • This page models quote removal only: no parameter expansion, command substitution, arithmetic expansion, pathname expansion, brace expansion, tilde expansion, aliases or here-documents.
        • It never runs the text. Nothing is passed to a shell, executed, stored or sent anywhere.
        • A shell word cannot contain a NUL byte, so text holding one is refused instead of quoted.
        • A quoted trailing newline survives, but command substitution strips trailing newlines and a terminal may add or remove one when you paste.
        • Which characters are special can differ in other shells, under other locales and inside [[ ]] or case patterns; the table follows POSIX sh and bash.
        • The text is limited to 8192 characters here, and decoding reads one word at a time.
