Data Anonymization Planner

This tool cannot certify or guarantee anonymization. Removing direct identifiers or meeting a chosen k threshold does not prevent linkage, inference, singling out, or disclosure using external data. Treat outputs as a planning preview and obtain qualified privacy review for real releases.

1. Load local data

Maximum 5 MiB, 10,000 rows, 100 columns. JSON must be an array of flat objects. Files remain in this browser; there is no network or persistent storage.

2. Classify and transform columns

Secret handling: The key is used in memory with HMAC-SHA-256, is never saved or exported, and is cleared on reset. Pseudonyms remain linkable wherever the same key and original value are reused. Do not use a guessable production key.
