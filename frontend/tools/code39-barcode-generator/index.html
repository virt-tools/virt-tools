Code 39 Barcode Generator

Turn upper-case text into a Code 39 barcode, with the check character and module count an asset label needs.

A-Z, 0-9, space and - . $ / + %; up to 40 characters, upper case only
Enter text to see its barcode.

Every Code 39 symbol is nine elements wide — five bars and four spaces, exactly three of them wide — plus a one-module gap between symbols, drawn here at a 1:3 narrow-to-wide ratio. The optional check character is the sum of the character values modulo 43, taken from 0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ-. $/+%, and is drawn before the stop symbol. Ten-module quiet zones sit at both ends; check the module width your label and scanner need and test-scan a print before a production run. Lower case and the full-ASCII pairs are not offered, and everything runs in your browser with no storage, uploads or network access.
