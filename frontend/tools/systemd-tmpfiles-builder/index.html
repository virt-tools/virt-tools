A tmpfiles.d line is seven space-separated fields: type, path, mode, user, group, age and an argument that only L entries use; a dash leaves a field unset. The type decides what runs: d, e, f, q and L act on systemd-tmpfiles --create, while d, e, q, r and x act on --clean, and age only limits cleanup, never creation. Files are read in lexical order, and a file in /etc/tmpfiles.d overrides the same-named file in /usr/lib/tmpfiles.d. Modes here stop at 1777, so setuid and setgid bits are not offered. This page only composes text: it reads no files, installs nothing and makes no network requests.
