CORS Preflight Simulator

Model browser CORS gates from request details and pasted response headers without making a network request.

Educational simulation: this page models a script-initiated CORS-mode fetch and never sends a request. Redirect targets are not followed. Private Network Access (PNA) is an explicit forced-preflight assumption; address-space detection, secure-context and mixed-content gates, permissions, browser rollout, preflight cache caps, client certificates, extensions, service workers, and redirect-tainted origins are outside its scope.
