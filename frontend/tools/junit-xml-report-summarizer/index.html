How the report is counted

Each <testcase> element is counted once. It is a failure when it contains a <failure> child, an error when it contains an <error> child, skipped when it contains a <skipped> child and passed otherwise; if a test case carries more than one of those children the order of precedence is failure, then error, then skipped. A test case belongs to the nearest enclosing <testsuite>, and a suite row counts only the test cases directly inside it, so the rows of a report with nested suites do not add up to the file total. The declared tests attribute is compared with the counted <testcase> elements and any difference is reported rather than hidden. The total time is the sum of the suite time attributes when every suite carries one, otherwise the sum of the test case times, otherwise it is left blank. Reports are parsed with a strict XML reader: a DOCTYPE declaration, an unknown entity, a mismatched or unclosed tag and a root other than <testsuites> or <testsuite> are refused with the reason instead of being guessed at. Only the first 50 failing test cases are listed.
