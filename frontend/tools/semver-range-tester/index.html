Semantic Version Range Tester

Test and sort a list of strict SemVer 2.0.0 versions against a practical npm-style range. Processing stays in your browser.

Test versions

Examples: 1.2.3, >=1 <2, 1.2.x, ~1.2, ^0.2.3, 1.2 - 2.3, or ^1.0 || ^2.0.

Supported syntax

  • Exact versions and comparators: 1.2.3, >=1.2.0, <2
  • Whitespace means AND; || means OR
  • Hyphen ranges: 1.2.3 - 2.3.4
  • Wildcards and partials: 1.x, 1.2.*, 1.2
  • Tilde and caret: ~1.2.3, ^1.2.3, ^0.2.3
  • Prerelease and build identifiers follow SemVer precedence

Prereleases: like npm, a prerelease is excluded unless its AND-group contains a comparator with a prerelease on the same major, minor, and patch version. Build metadata does not affect precedence.
