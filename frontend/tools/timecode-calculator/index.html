SMPTE Timecode Calculator

Add, subtract, compare, or convert timecode using exact rational frame rates. Drop-frame skips clock labels to track elapsed time; it never removes media frames.

Inputs

Syntax: [-]HH:MM:SS:FF, or use a semicolon before frames for drop-frame. Frame fields must be below the nominal rate.

Result

Elapsed seconds = exact frames ÷ exact frames/second. At 29.97 DF, 00:10:00;00 is frame 17,982—not frame 18,000.
