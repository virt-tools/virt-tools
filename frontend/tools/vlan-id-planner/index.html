An 802.1Q VLAN tag carries a 12-bit VLAN identifier, so IDs run from 1 to 4094: 0 and 4095 are reserved as priority tags, and 1002 to 1005 are reserved for legacy Token Ring and FDDI use. This planner takes the lowest free IDs in the range you give, skipping reserved IDs and any you list as in use, and reports how fragmented the result is and where the largest remaining block sits. The tag value for each VLAN is PCP × 8192 + DEI × 4096 + VLAN ID, printed as a four-digit hexadecimal 802.1Q tag control field. It does not know which VLANs your switches already carry, which ports are access or trunk ports, or which IDs your provider reserves, so check the plan against the switch configuration before applying it. Everything runs in your browser with no storage, uploads or network access.
