Keyboard Layout Converter

Retype text that came out in the wrong keyboard layout. Each character is traced back to the physical key that produced it, and the same key is read on another layout.

Keys of the chosen layouts 




A key sends the same electrical code whatever is printed on it, so switching layouts remaps by position, not by letter: on Dvorak the QWERTY H key types d and the E key types ., which is why d.nnr reads back as hello. Digits and punctuation move with their keys too. Spaces and line breaks pass through unchanged, and a character that the first layout cannot type at all (an accent, a currency sign, an emoji) is left as it is and counted. Only the ANSI US layouts QWERTY, Dvorak and Colemak are covered, and only the unshifted and shifted levels, so AltGr characters are not remapped. Everything runs in your browser; nothing is stored and nothing is sent.
