    How the name is assembled
    PartValue

    An iqn., eui. or naa. name, exactly as your initiator or target reports it.

    Verdict

      An iSCSI qualified name is built from four parts: the type designator iqn., the date code yyyy-mm, the reversed domain name of the naming authority, and an optional suffix introduced by a colon. The date is the first month in which that authority owned the domain, which is why the same domain can carry different names over time. The page lower-cases the domain, because DNS names are case-insensitive and an iSCSI name is compared as a normalized lower-case string, and it drops one trailing dot. The name is limited to 223 bytes; the suffix is yours to assign as long as it uses letters, digits, dots, hyphens and colons. An eui. name is the type designator followed by exactly sixteen hexadecimal digits, and a naa. name is the designator followed by an even number of hexadecimal digits up to 32. The same string form names an initiator or a target: the role comes from the login, not from the name. Everything runs in your browser; nothing is sent or stored.
