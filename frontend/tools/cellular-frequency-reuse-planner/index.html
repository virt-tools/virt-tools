A cluster of N cells repeats only for N = i² + ij + j², so a hexagonal plan allows N = 1, 3, 4, 7, 9, 12, 13, 19 and not 2, 5, 6 or 8. The nearest co-channel cells sit at D = R√(3N), and with an equal-power first tier all at that distance the cell-edge ratio is S/I = (√(3N))n / i0, where i0 is the number of interfering cells the sector sees. This is the standard hexagonal estimate: equal powers, equal interferer distances, a pure power law and no terrain, and it is optimistic against a worst-case geometry. Channels per cell is total ÷ N rounded down, before any trunking loss.
