Project Estimate Range

Combine optimistic, most-likely, and pessimistic work estimates analytically and with reproducible simulation.

Estimate model, not a promise: results depend entirely on the supplied ranges and model assumptions. Analytical confidence ranges use a normal approximation. Simulation percentiles describe this model, not guaranteed delivery probabilities.

Work items

Values are generic units (time, cost, points, etc.). Require 0 ≤ optimistic ≤ most likely ≤ pessimistic. Names may be quoted CSV. Up to 500 rows.

Model settings

This is a deliberately limited perfect rank-dependence scenario, useful for common-direction risk. It does not estimate a correlation coefficient, partial dependence, causal coupling, or schedule dependencies. Blank groups remain independent.
