Kubernetes Manifest Inspector

Summarize resources and cross-check common local references without uploading manifests.

Advisory subset inspector: this is not API-server dry-run, OpenAPI schema validation, policy admission, Helm/Kustomize rendering, or a security audit. YAML support is limited to indentation-based mappings/sequences and ordinary scalars; anchors, aliases, tags, directives, merge keys, block scalars, and flow-style YAML are rejected. Only selected built-in fields and common direct references are inspected. Secret payload values are never rendered or exported.

Limits: 1 MiB UTF-8, 100 documents, 20,000 nonblank lines, nesting depth 30, and 100,000 parsed values.
