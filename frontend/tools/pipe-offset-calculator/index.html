Working

StepWorkingValue

A standard offset turns the pipe once through the fitting angle: the travel between the two fitting centres is the offset divided by the sine of that angle, and the run along the original axis is the offset divided by its tangent. A rolling offset adds a second plane, so the two entered offsets are first combined into the true offset — the square root of the sum of the squares — and the roll angle is the direction of that true offset, measured from the horizontal component towards the vertical one. The cut length subtracts each fitting's centre-to-face take-out from the travel. Take-out dimensions differ between standards, schedules and manufacturers, so read them from the fitting chart that governs the job; support spacing, expansion, and any code requirement are outside this calculator.
