The planner takes the larger of capacity and coverage counts. Capacity divides aggregate demand by usable per-AP throughput after headroom; coverage divides floor area by the reliable cell area. Both round up. These are first-pass budgets, not an installation survey.

This is a comparative sketch, not a predictive RF survey. Estimated RSSI uses transmit power minus loss at 1 metre, log-distance path loss, each same-floor partition crossed, and the configured loss for every floor crossed. Cross-floor paths omit partitions. It does not model antenna patterns, frequency-specific materials, reflection, interference, roaming or client capability; walls are 12 dB, doors 6 dB, windows 3 dB and concrete 20 dB by construction. Verify with measured surveys. Nothing is uploaded. A design stays in memory unless you save it in this browser or download the versioned JSON file.
