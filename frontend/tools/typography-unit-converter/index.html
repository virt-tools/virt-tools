Typography & Print Unit Converter

Convert a type size or print measurement between points, picas, twips, inches, millimetres, centimetres, quarter-millimetres and CSS pixels, using the exact ratios every print workflow and browser already agrees on.

A pica is 12 points, a twip is one twentieth of a point, and CSS defines its pixel as exactly 1/96 inch, so 1 pt is 1.3333 CSS pixels. The continental European Didot point of about 0.376 mm and the 12-point cicero are a separate system and are not converted here. Values are shown to four significant digits, and entering a rounded figure back gives the original size to within that rounding. Everything is calculated in your browser; nothing is sent or stored.
