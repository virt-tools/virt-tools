HDR Transfer Function Converter

An HDR or SDR transfer function turns a signal level into light. This page converts in both directions for PQ (SMPTE ST 2084, HDR10 and Dolby Vision), HLG (BT.2100 broadcast HDR), BT.1886 (the SDR reference display) and sRGB, showing the normalised signal, the 10-bit and 12-bit code values and the luminance in cd/m². Everything runs locally.

Input

Whole number from 0 to 1023; 10-bit is the usual HDR10 and HLG carrier.

Display luminance in nits; 203 is the HLG reference white on a 1000 cd/m² display.

The nominal HLG peak is 1000 cd/m²; the system gamma follows the peak you enter.

How the curves work

PQ — SMPTE ST 2084. PQ is absolute: every code value means a fixed luminance from 0 to 10,000 cd/m², whatever the display. The EOTF is

  • L = 10000 × (max(N^(1/m2) − c1, 0) / (c2 − c3 × N^(1/m2)))^(1/m1) with m1 = 2610/16384, m2 = 2523/4096 × 128, c1 = 3424/4096, c2 = 2413/4096 × 32 and c3 = 2392/4096 × 32.
  • Here N is the code value divided by 1023 (10-bit) or 4095 (12-bit). The inverse is N = ((c1 + c2 × Y^m1) / (1 + c3 × Y^m1))^m2 with Y = L / 10000.
  • Published anchors: 10-bit 100 is about 0.31 cd/m², 512 about 92.7 cd/m², 769 about 999 cd/m² and 1023 exactly 10,000 cd/m². 100 cd/m² falls between codes 520 and 521.

HLG — ITU-R BT.2100. HLG is relative: the signal is an OETF-encoded scene value, and the display applies a system gamma that depends on its peak, γ = 1.2 + 0.42 × log10(Lw / 1000), so L = Lw × E^γ with E the inverse OETF of the signal. The OETF uses sqrt(3E) up to 1/12 and a × ln(12E − b) + c above it, with a = 0.17883277, b = 0.28466892 and c = 0.55991073.

  • At a 1000 cd/m² peak the gamma is 1.2 and the 75 % signal lands on about 203 cd/m², the reference white that graphics and subtitles are authored against; 50 % is about 50.7 cd/m².
  • At a 100 cd/m² peak the gamma is 0.78, so the same signal is much darker. The page accepts peaks from 100 to 1000 cd/m², the nominal HLG range.
  • HLG extended-range signals above the nominal peak are not modelled here; broadcast HLG normally stays inside it.

BT.1886. The SDR reference EOTF is a pure 2.4 gamma with a black level of zero: L = Lw × V^2.4, inverted as V = (L / Lw)^(1/2.4). The classic reference white is 100 cd/m², which is why the peak defaults to 100.

sRGB. The IEC 61966-2-1 curve has a 12.92 linear toe below 0.04045 and a 2.4 power above it, scaled by 1.055: L = Lw × ((V + 0.055) / 1.055)^2.4. It is display-referred, so the peak is the white level.

These are signal-domain transfer functions. A real display adds panel calibration, tone mapping and ambient light, so use a meter and the display's own calibration for measurements. The page performs no storage, uploads or network requests.
