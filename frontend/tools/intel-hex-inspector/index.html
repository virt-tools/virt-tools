Intel HEX Inspector

Paste an Intel HEX file and check it record by record: checksums, addresses, gaps, overlaps and the entry point.

One record per line, starting with a colon. Blank lines are ignored; comments are not part of the format.

Each line is a record: :LLAAAATT data CC, where LL is the number of data bytes, AAAA the load offset, TT the record type and CC the checksum — the two's complement of the bytes from the length field to the last data byte, so a correct record sums to zero. Type 00 carries data, 01 ends the file, 02 sets a 64 KiB segment base, 03 a start address as CS:IP, 04 the upper 16 bits of a 32-bit base and 05 a 32-bit start address. A data record's byte address is the current base plus the load offset, wrapped at 4 GiB in linear addressing and at 64 KiB within the segment in segmented addressing. Everything is checked in your browser; nothing is uploaded or stored.
