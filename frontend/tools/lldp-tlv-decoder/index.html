LLDP TLV Decoder

Paste the hex bytes of an LLDP data unit and read every type-length-value field: the chassis and port identifiers, time to live, system name and description, the capability bitmaps, management addresses and the organizationally specific TLVs.

A payload paste starts at the first TLV. Frame mode reads the 14-byte Ethernet header, skips up to two 802.1Q tags and checks that the EtherType is 0x88CC. Spaces, colons, commas, 0x prefixes and dump offset labels are ignored.

Each TLV starts with a 16-bit header: a 7-bit type and a 9-bit information-string length, then that many value octets. An LLDPDU begins with the Chassis ID (type 1), Port ID (type 2) and Time To Live (type 3) TLVs in that order, may carry any of the optional types 4 to 8 and type 127, and ends at a type 0 TLV with no value. The Chassis ID and Port ID values begin with a subtype octet: 1 to 7 name a component, alias, MAC address, network address, interface name or locally assigned string (the port ID subtypes differ at 6, agent circuit ID), and a MAC address is exactly six octets. The System Capabilities value is two 16-bit bitmaps, supported then enabled: bit 0 other, 1 repeater, 2 bridge, 3 WLAN access point, 4 router, 5 telephone, 6 DOCSIS cable device, 7 station only, 8 C-VLAN component, 9 S-VLAN component, 10 two-port MAC relay. A Management Address value is a length-prefixed address with an address-family subtype, then an interface numbering subtype, a 4-octet interface number, an OID length and the OID. An organizationally specific value is a 3-octet OUI and a 1-octet subtype: 00-12-0F is IEEE 802.3 (subtype 1 MAC/PHY status, 2 power via MDI, 3 link aggregation, 4 maximum frame size), 00-80-C2 is IEEE 802.1 (subtype 1 port VLAN ID, 3 VLAN name, and the congestion-notification and ETS extensions), and 00-12-BB is TIA TR-41 for LLDP-MED. The MAC/PHY status carries a one-octet autonegotiation flag byte (bit 0 supported, bit 1 enabled), the 16-bit advertised PMD capability and the 16-bit operational MAU type. A time to live of 0 is a shutdown advertisement: the neighbour should drop the entry at once, while a normal value is renewed at one quarter of it with the default hold multiplier of 4 (a 120 s TTL is a 30 s transmit interval). Values this page does not decode are shown as hex, not guessed at, and the decoder does not verify checksums, timers or whether a neighbour would accept the advertisement. Everything runs in your browser; nothing is sent anywhere.
