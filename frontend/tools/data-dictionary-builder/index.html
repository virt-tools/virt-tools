Data Dictionary Builder

Profile tabular data and document its fields locally, with observed facts kept separate from authored meaning.

Scope: inferred types, samples, ranges, and counts describe only the loaded rows. They do not establish semantics, privacy status, ownership, constraints, or future validity. Generated JSON Schema is a lossy draft and must be reviewed before use for validation.

Source data

Distinct counts stop at 10,000 unique values; samples show at most five values. Ranges appear only when every nonblank value has one comparable inferred type.

Dictionary

    Nothing is sent over the network. Explicit browser save stores documentation and the observed profile—including sample values—in this browser; it does not store source rows. Clear memory does not delete that saved draft.
