IPv6 Address Explainer

Expand, canonicalize, classify, and inspect an IPv6 address or prefix using exact local arithmetic.

No DNS or network access: this explains syntax and well-known address ranges only. A zone ID identifies a local interface scope and is preserved for display but excluded from all address and prefix mathematics.

Examples: ::1, fe80::abcd%eth0/64, ::ffff:192.0.2.128/96
