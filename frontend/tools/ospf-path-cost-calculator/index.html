OSPF Path Cost Calculator

Derive Cisco IOS-style OSPFv2 interface metrics and add the outgoing-interface costs along a path.

Mbps · Cisco IOS default is 100
One outgoing interface per line, in Mbps; up to 24 links

Uses Cisco IOS auto-cost: floor(reference ÷ interface bandwidth), with a minimum of 1 and a per-interface maximum of 65,535. A manually configured OSPF cost takes precedence. OSPF costs are directional, and the reference bandwidth must be consistent across the routing domain; other implementations can differ. This calculator runs locally and does not inspect a router or network.
